# .github

Organization-wide GitHub configuration for **ms3-systems**.

This repo holds files that apply across the organization rather than to a
single project:

- `profile/README.md` — the org's public profile page (shown on
  [github.com/ms3-systems](https://github.com/ms3-systems))
- Shared issue/PR templates and community health files, if/when added

No application code lives here — see
[`ms3`](https://github.com/ms3-systems/ms3) for the app and
[`ms3-fleet`](https://github.com/ms3-systems/ms3-fleet) for deployment.
